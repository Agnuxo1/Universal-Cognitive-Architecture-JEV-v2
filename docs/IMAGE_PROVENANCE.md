# Image provenance

Four final PNG illustrations were generated on 2026-09-22 using OpenAI's built-in
image generation tool. No stock image or external image was used. The tool does
not expose a selectable model ID or a verified backend model name, so we do not
claim a particular ChatGPT/image model version. It was the available native OpenAI
image generator for this task. One routing image received a corrective edit.

The illustrations explain the design; implementation and tests define actual
behavior. Decorative labels are not benchmark evidence. Files are included in
this repository, not linked to temporary local image paths.

## Prompt specifications

**Header:** Professional wide GitHub README hero. Title COGNITIVE ARCHITECTURE;
subtitle JEV • Evidence-driven orchestration. Dark navy, restrained cyan/amber,
abstract 8×8 knowledge board connected to modular compute blocks and an evidence
checkpoint. No brains, robot faces or unsupported performance claims. Landscape.

**Routing:** ROUTE ONLY WHEN NEEDED. TASK → LOCAL CHECKS; deterministic VALIDATED
CACHE route and optional JEV ROUTER → BOUNDED WORKER → EVIDENCE GATE → RESULT.
Footer: Deterministic work first. Model calls are optional. Corrective edit replaced
small labels with Choose collaboration mode; Call cap and provider timeout;
Run declared acceptance checks; Passed the declared checks; Deterministic results
only. Removed decorative corner claims.

**Memory:** MEMORY WITH EVIDENCE. Three panels KNOWLEDGE GRAPH, RESULT CACHE,
CHECKPOINT. Input fingerprint, verified artifact, task status, artifact fingerprint,
next action. Strip VERSION + INPUTS + CHECKS. Footer: A path is an index, not a
complete memory. Match header palette and landscape format.

**Consensus:** CONSENSUS NEEDS VERIFICATION. COMPACT EVIDENCE branches to VIEW A
and VIEW B, converges to CRITIC + SYNTHESIS and EXECUTABLE CHECKS, with ACCEPT or
REVISE outcomes. CALL + TIME BUDGET frame. Footer: Agreement alone is not evidence.
No metrics, robot faces or brands. Match header palette and landscape format.
